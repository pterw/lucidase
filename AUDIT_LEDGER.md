## Remediation Log

### 2026-10-02 hardening pass (fix/genomepulse-hardening)

**Methodology.** The audit above passed the Python suite while the browser code was broken, so this pass started from diagnosis. Independent reviews of the web worker, the Python desktop stack, the graph tool and the knowledge-base pipeline produced a findings register, and the controller inspected the page in Chrome. Five root causes explained the findings:

- **RC1. No test seam for the browser code.** The green Python suite certified nothing users run (P0-004 shipped).
- **RC2. Genotype-string matching instead of alt-allele counting against plus-strand ref/alt.** This produced P0-006, P0-007, P1-026 and part of P1-025.
- **RC3. Several hand-maintained copies of the knowledge and the logic.** The JS KB, the Python dict, the pipeline JSON, and the Python and JS engines drifted apart (P1-022).
