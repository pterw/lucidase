Lucide line icon rendered as a currentColor mask — use beside text labels; never as the only carrier of meaning.

```jsx
<Icon name="file-up" size={16} />
<Icon name="triangle-alert" label="Notice" />
```

- Loads SVGs from unpkg lucide-static@0.469.0 (substitute for the source's emoji icons — flagged in readme).
- Inherits colour from the parent; size 14/16/20 only.
