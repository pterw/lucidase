Shape-coded result mark — the karyogram's dot language used everywhere: filled = found, ring = not found, dashed ring = not on your chip, half = unclear, small dot = not checked.

```jsx
<StateMark state="supported_and_observed" withLabel />
<StateMark state="not_tested_by_array" />
```

- Readable without colour (shape) and without sight (label). Replaces coloured state chips.
