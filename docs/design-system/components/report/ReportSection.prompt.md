A report section on the ledger grid: heading + plain purpose line in a 200px margin column, content beside it, a hairline rule above. Replaces cards; wraps to one column on narrow screens.

```jsx
<ReportSection id="pharmacology" title="Pharmacology" aside="How your genes may affect the way some drugs work in your body.">
  <FindingRow … />
</ReportSection>
```
- Space between sections is large (64px); inside a section it is tight.
